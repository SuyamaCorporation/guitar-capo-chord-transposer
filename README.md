# ギター カポ コード 移調ツール

カポの位置（0〜12フレット）と元コード名からサウンドコード（実音）を計算するギタリスト向けツール。

## 機能
- 順引きモード: カポ位置 + フォームコード → サウンドコード（実音）
- 逆引きモード: サウンドコード → カポ位置 + フォームコード一覧（開放弦コードにスター印）
- 対応コード種類: Major / minor / 7 / m7 / maj7
- 移調一覧表（カポ0〜12 × 全12音）

## 使い方
1. 「順引き」タブ: カポ位置・コードルート・種類を選択して計算
2. 「逆引き」タブ: 弾きたいサウンドコードを選択して使えるカポ+フォームを一覧表示
